# HLWS2 自分の軸と学びの地図（授業用サイト）

ヒューマニスティック・リーダーシップWS2（第6回）で使う、授業専用のサイトです。オープンキャンパス用の「経済経営学部 学びナビ」（3分診断・キーワード診断）とは別のものです。

| ページ | URL（GitHub Pages の例） | 内容 |
|---|---|---|
| トップ（使い方） | `https://ユーザー名.github.io/hlws-tools/` | STEP 1〜5 の進め方。Gem・学びの地図・履修プランナーへのボタン |
| 学びの地図 | `…/hlws-tools/map/` | 価値観（★いちばん大事2つ・大事5つ）と分野（2つ）を選び、近いモジュールと授業例を見る |
| 履修プランナー | `…/hlws-tools/planner/` | モジュールの科目・学期・時間割を見る |

- Gemのまとめに出すリンク：`…/hlws-tools/map/?v1=いちばん大事1,いちばん大事2&f=分野1,分野2`（`v2=` で「大事」も指定できます）
- トップの「深掘りGemを開く」ボタン：`index.html` の下のほうにある `var GEM_URL = '';` の `''` の中に、Gemの共有リンクを貼ると使えるようになります
- `keyword/` と `diagnosis/` は、古いリンクから来た人を、学びの地図・トップへ自動で移動させるためだけのページです

## 中身を変えるとき

- キーワード（価値観・分野）と重み：`data/keyword.json` の `hlws`
- 選べる数：`data/keyword.json` の `hlws.limits`（`valueTop`・`valueSub`・`field`）、「大事」の重み：`hlws.subWeight`
- 履修プランナーの科目：`data/courses.json`、モジュール：`data/modules.json`

HTMLファイルをダブルクリックして開くと動きません（ブラウザの制限）。確認は公開したURLで行ってください。
